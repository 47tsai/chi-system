# logo

來源：chi-system-old 的 logo/（HEAD 436f028），全部 16 檔直接搬用，齊已定案站點 ID 命名。

- 正菱形加特殊字體 C；特殊字體是 logo 的靈魂，轉成向量外框時必須保留字體原形。
- 菱形色跟站識別色：每站的 logo 就用那站的識別色。
- C 顏色：深色模式白 C、淺色模式黑 C，favicon 與其他用途一律白 C。
- 檔名：`chi/fg/merch/nav/h/status-w|b.png`＋單色 `black-w`、`white-b`。
  `-w`＝白 C（深色模式用），`-b`＝黑 C（淺色模式用）。
- `logo.svg` 是正本（chi，藍菱形白 C）；新站 logo 由它改菱形色再輸出兩張 PNG。
